# ChatGPT15

Personal lightweight OpenAI API client for iOS 15, wrapped in WKWebView.

## Build

Open the repository's **Actions** tab, choose **Build TrollStore IPA**, and run the workflow. Download the **ChatGPT15-TrollStore** artifact when it finishes. Unzip the downloaded artifact to get **ChatGPT15.ipa**, then transfer it to the iPhone and open it with TrollStore.

The OpenAI API key is entered inside the app at runtime. Do not commit an API key to this repository.
